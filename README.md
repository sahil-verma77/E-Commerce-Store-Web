# 🛍️ E-Commerce Store

A responsive e-commerce website built with **HTML, Tailwind CSS, custom CSS, and JavaScript**. The project provides an interactive shopping experience where users can browse products, search for items, view product details, and manage their cart and wishlist.

🔗 **Live Demo:** [E-Commerce Store](https://sahil-verma77.github.io/E-Commerce-Store-Web/)

## ✨ Features

* **Product Browsing:** Explore products fetched from an external API.
* **Product Search:** Search for specific products by name using the search bar.
* **Product Details:** View individual product information on a dedicated page.
* **Shopping Cart:** Add products to the cart and remove them when needed.
* **Wishlist:** Save products to a wishlist and remove them whenever desired.
* **Persistent Storage:** Cart and wishlist data remain available after refreshing the page.
* **Category-Based Filtering:** Filter products by category to find items that match your interests.
* **Responsive UI:** A user-friendly interface styled with Tailwind CSS and custom CSS.

## 🛠️ Technologies Used

* **HTML5** — Website structure and content.
* **Tailwind CSS** — Utility-first styling.
* **CSS3** — Custom styling and visual enhancements.
* **JavaScript (ES6+)** — Dynamic functionality and user interactions.
* **External API** — Fetching product data.
* **Local Storage** — Persisting cart and wishlist data in the browser.
* **GitHub Pages** — Hosting the live website.

## 📂 Project Structure

```text
E-Commerce-Store-Web/
│
├── index.html
├── product-details.html
├── cart.html
├── wishlist.html
│
├── css/
│   └── style.css
│
└── js/
    └── main.js
```

The `index.html` file serves as the homepage, while the other HTML files provide dedicated pages for product details, the shopping cart, and the wishlist. The `css/` and `js/` directories contain the project's styling and JavaScript file.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

* A modern web browser.
* Git (optional, for cloning the repository).
* An internet connection to load product data from the external API and any remotely hosted resources.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/sahil-verma77/E-Commerce-Store-Web.git
```

**2. Navigate to the project directory**

```bash
cd E-Commerce-Store-Web
```

**3. Run the project**

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No build step is required for this static website.
